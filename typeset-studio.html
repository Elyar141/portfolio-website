Case Study

Typeset
Studio

A kerning tool for designers with unreasonably strong opinions about the space between letters. Built for precision, powered by obsession.

Project Visual

Overview

Typeset Studio was born out of frustration with existing kerning tools that felt either too technical or too limited. The goal was to create something that felt like a natural extension of the designer's eye: immediate, precise, and satisfying to use.

Problem

Typography tools often separate the visual and technical aspects of kerning. Designers would set values numerically without seeing the full context, or rely on subjective visual feedback without any systematic approach. This disconnect led to inconsistent results across type families.

Solution

A split-view interface that shows kerning pairs in real type context while exposing the underlying metrics. The tool learns from the designer's adjustments and suggests corrections across related character pairs, dramatically reducing the time to achieve consistent spacing.

Interface Detail

Outcome

Tested with twelve type designers over six weeks. Average time to kern a full character set dropped by 40%. Several described it as the first tool that matched how they actually think about spacing rather than how software assumes they do.
